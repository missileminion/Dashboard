# Personal health and productivity dashboard

A one-person dashboard that runs entirely in the browser: Google Health (Fitbit Air, read-only), a focus timer, a Stickynote and a gym log.

- Start it locally: double-click `start.command` (real data on :8081, demo data on :8082).
- Copy `app/config.example.js` to `app/config.js` and paste your Google OAuth client ID. Never put a client secret in this app.
- Personal data (`stickynote.md`, `gym-log.json`) is ignored by git on purpose.
